# Contributing

The most valuable contribution right now is **testing and telling us what you found**. See the
[testing guide](docs/TESTING.md).

## Reporting

- **Bugs and confusing behaviour:** the in-app Feedback page, or
  [Stables Community on Telegram](https://t.me/stablescommunity).
- **Security:** privately, and never as a public issue. Read [docs/SECURITY.md](docs/SECURITY.md).

A good report says what you did, what you expected, and what happened, with the version from Settings
and a transaction id if money was involved.

## Code

This repository distributes the applications and their documentation. The application source is
developed in the Council's working repository and is not yet open for pull requests. That will change,
and this document will say so when it does.

If you want to work on Stables, say hello in the community group and tell us what interests you.

## Documentation

Corrections to anything in `docs/` are welcome as issues or pull requests. Accuracy matters more than
polish here: if a document claims something the software does not do, that is a defect and we want to
know.

## Tone

Two rules govern everything written here:

1. **Say only what is true, at the level it was observed.** Where something is untested, say so.
2. **Write for someone who does not know what a blockchain is.** Jargon that survives is jargon that
   earns its place.
