**PASS, CHIP-WITHDRAW-01-R4, 2026-10-08.** Complete D1 signature verification and D2 vault
payout transactions settled on Minima mainnet using signatures generated by the
current Java Card applet in jCardSim. No signature or covenant check was disabled.
This is L2 evidence for the named candidate withdrawal paths, under the assumed
hardware and certification guarantees. It is not physical-chip validation.

The first cumulative authorisation was 250 units. The second was 290 units, and
the vault correctly paid only its 40-unit increment. Both registered lab peers
observed the same canonical blocks with at least one confirmation each. Closing
reads show **290 paid + 310 remaining = 600 funded**, account cumulative debit 290,
highest redeemed key index 2, and both owner payout coins sendable. All ten native
helper coins returned to the laboratory wallet, 0.00000010 MINIMA, without burn.

## Findings, limitations and next decision

The named Minima-side withdrawal feasibility question is answered positively.
This corrects the earlier status that complete chip-authorised withdrawal had not
been mined. The cumulative D1 branch and sequential D2 settlements are now tested
in these baseline variants, rather than inferred from the old signature-core dry runs.

The deployed app and its software-trusting vault were not upgraded. Physical
card installation, timing, interruption/atomicity and randomness checks, secure
provisioning and certification, production app integration, complete other-branch
and long-term availability validation, and independent LX16/protocol review remain.
These tests do not prove hardware key non-extraction or that a compromised vendor
cannot certify bad software. The hardware premise remains explicit.

Two earlier defects were recorded without posting invalid transactions: R2 used
the mint placeholder token ID instead of the confirmed token identity; R3 called
txnbasics twice and duplicated proofs. Corrective runs had new identities/hashes.
No platform-limit breach occurred. All sources and negative results remain available.

Formal R4 execution took approximately **6.9 minutes**, four honest
withdrawal transactions and eight unposted refused attempts. Preparation included
two valueless token mints and three canonical setup controls. The founder supplied
0.000001 MINIMA to the isolated lab; tiny native colouring created the tokens, with
no transaction burn and all helper native amounts returned.

**Recommendation:** continue to a real two-card laboratory validation and app
integration campaign, retaining the current production limitations. Founder review
is still needed before promoting this evidence into the binding knowledge base,
protocol documentation map and handshake capsule. No economic policy or production
release was approved. The current capsule's authority sources remain unchanged.
