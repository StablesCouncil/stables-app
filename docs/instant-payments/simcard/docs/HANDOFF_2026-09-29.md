# Handoff: Stables Instant payments (offline payment layer), 2026-09-29

Read this first in a new session. It is the single place that says where the work stands.

## 1. What this project is
Savings (the on-chain Minima wallet) plus **Instant payments**, a checking balance that pays device to device:
- no internet needed;
- any amount, as often as wanted;
- final at the tap;
- no expiry, no user bond.

Built in stages:
- **Stage 1:** the Stables Android app plays the "chip". This is what exists now.
- **Stage 2:** a Java Card SIM or card, simulated only so far.
- **Stage 3:** a Minima node on the chip (vision).
